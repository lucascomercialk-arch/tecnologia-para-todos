# 🌍 Guia de Internacionalização (i18n) — Tecnologia para Todos

Este documento descreve como o suporte multilíngue (**Português `pt`**, **Espanhol `es`** e **Inglês `en`**) está organizado e como mantê-lo à medida que novas aulas, termos e telas forem adicionados.

---

## 1. Arquitetura dos Arquivos

| Arquivo | Responsabilidade |
| :--- | :--- |
| `js/i18n.js` | Motor de tradução (`TPT.i18n`): detecção inicial via `navigator.language`, persistência em `localStorage` (`tpt_lang`), interpolação `{variavel}`, fallback para `pt` e atualização segura do DOM via `textContent`/atributos. |
| `data/i18n/ui.js` | Dicionário `window.TPT_TRANSLATIONS` com todos os textos da interface (`pt`, `es`, `en`): cabeçalho, Home, controles das aulas, glossário, playground, tradutor de erros Python, aba de melhorias/tasks e rodapé. |
| `data/i18n/lessons-i18n.js` | Dicionário `window.TPT_LESSONS_I18N` com as traduções `es` e `en` de títulos, subtítulos, tópicos e cards das aulas (o conteúdo base `pt` permanece em `data/lessons.js`). |
| `data/i18n/glossary-i18n.js` | Dicionário `window.TPT_GLOSSARY_I18N` com as traduções `es` e `en` de todos os termos do glossário, indexados pelo campo `term` de `data/glossary.js`. |

---

## 2. Regras de Consistência Terminológica

Para evitar variações entre a interface, as aulas e o glossário, adote estes termos padrão:

| Conceito | Português (`pt`) | Español (`es`) | English (`en`) |
| :--- | :--- | :--- | :--- |
| Trilha | Trilha de Aulas | Ruta de Clases | Lessons Path |
| Aula | Aula `{n}` | Clase `{n}` | Lesson `{n}` |
| Glossário | Glossário | Glosario | Glossary |
| Botão principal do editor | Rodar Código | Ejecutar Código | Run Code |
| Botão de exemplo | Testar no Playground | Probar en Playground | Try in Playground |
| Terminal de saída | Console | Consola | Console |
| Variável | variável | variable | variable |
| Lista | lista `[ ]` | lista `[ ]` | list `[ ]` |
| Repetição | repetição / loop | bucle | loop |
| Indentação | indentação (espaços) | sangría (espacios) | indentation (spaces) |
| Comentário | comentário (`#`) | comentario (`#`) | comment (`#`) |
| Erro | erro (bug) | error (bug) | error (bug) |

> **Regra importante:** palavras-chave e funções nativas do Python (`print()`, `input()`, `len()`, `int()`, `float()`, `if`, `elif`, `else`, `for`, `while`, `append()`, `remove()`, `in`, `range()`) **não são traduzidas** nos blocos de código nem nos títulos dos comandos, para que o aluno reconheça exatamente o que precisa digitar no editor.

## 3. Como Manter e Adicionar Traduções

### A. Adicionar um texto novo na interface (HTML / JS)
1. Adicione a mesma chave dentro de `pt`, `es` e `en` em `data/i18n/ui.js` (ex.: `home.hero.novoBotao`).
2. No `index.html`, use:
   - `data-i18n="chave"` para textos (`textContent`);
   - `data-i18n-placeholder="chave"`, `data-i18n-title="chave"` ou `data-i18n-aria-label="chave"` para atributos.
   - **Nunca** coloque HTML dentro das strings de tradução (o motor aplica tudo via `textContent` para proteção Anti-XSS).
3. Nos scripts (`js/app.js`, `js/playground.js`, `js/issues.js`), use `TPT.i18n.t('chave', { variavel })`.

### B. Adicionar uma nova aula ou novo card
1. Adicione a aula/card em `data/lessons.js` com `id` único (ex.: `aula-3`, `a3-def`).
2. Adicione a entrada correspondente em `TPT_LESSONS_I18N.es` e `TPT_LESSONS_I18N.en` em `data/i18n/lessons-i18n.js` usando o mesmo `id`.

### C. Adicionar uma nova palavra no glossário
1. Adicione o termo em `data/glossary.js` (`term`, `category`, `simple`, etc.).
2. Adicione a tradução indexada pelo mesmo `term` em `TPT_GLOSSARY_I18N.es` e `TPT_GLOSSARY_I18N.en` em `data/i18n/glossary-i18n.js`.

### D. Adicionar um novo idioma no futuro (ex.: Francês `fr` ou Crioulo Haitiano `ht`)
1. Adicione a seção do idioma em `data/i18n/ui.js`, `data/i18n/lessons-i18n.js` e `data/i18n/glossary-i18n.js`.
2. Inclua o código em `SUPPORTED_LANGS`, `HTML_LANG_MAP` e `normalizeLang()` em `js/i18n.js`.
3. Adicione o botão `data-set-lang="..."` no `.lang-switcher` do `index.html`.
